# Exercises

> Common interview questions with sample discussions, code, and diagrams.

**Work each exercise yourself before reading the solution.** Use the
[four-step framework](../study-guide/interview-approach.md): outline use cases and constraints,
sketch a high level design, design core components, then scale the design. Reading a solution you
haven't attempted teaches you the answer, not the process.
