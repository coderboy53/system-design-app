# Appendix

You'll sometimes be asked to do **'back-of-the-envelope' estimates**. For example, you might need to
determine how long it will take to generate 100 image thumbnails from disk, or how much memory a
data structure will take. The **powers of two table** and **latency numbers every programmer should
know** are handy references.
